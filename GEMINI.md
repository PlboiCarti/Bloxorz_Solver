# GEMINI

## rules

- khi vào session, đọc theo thứ tự: `docs/index.md` (Map) → `docs/status.md` (Status + delete-zone) → chỉ phần `docs/engine.md` liên quan tới task. Không đọc lại toàn bộ docs.
- các quyết định lớn, quan trọng, mang tính cả dự án cần phải được ghi lại sau khi thực hiện vào file engine.md tại /docs/engine.md với format mỗi quyết định là 1 dòng, ngắn gọn, trình bày gạch đầu dòng.
- tuy dùng uv nhưng vẫn cần thêm các dep vào `requirements.txt` bằng lệnh sinh tự động
- chỉ code sửa đổi liên quan đến game engine, không sửa gui hay implement solver
