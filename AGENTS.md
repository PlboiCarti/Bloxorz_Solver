## Engine API contract (authoritative; full version in `docs/api.md`)

```python
from game import (
    Action, Board, BridgeStates, Cell, Engine, Orientation, State,
    TileType, load_board, occupied_cells, parse_board,
)
```

Conventions: `Cell = tuple[int, int]` in `(row, col)`, origin top-left. The block
anchor is its **top-left** occupied cell.

```python
class Action(Enum):     # legal_actions order is fixed UP, DOWN, LEFT, RIGHT, SWITCH_CUBE
    UP; DOWN; LEFT; RIGHT; SWITCH_CUBE  # SWITCH_CUBE legal only in split mode (TV2)

class Orientation(Enum):
    STANDING    # occupies (r,c)
    HORIZONTAL  # occupies (r,c), (r,c+1)
    VERTICAL    # occupies (r,c), (r+1,c)

@dataclass(frozen=True, slots=True)
class State:  # immutable + hashable (use directly in visited sets / priority queues)
    block_position: Cell
    orientation: Orientation
    bridge_states: tuple[bool, ...] = ()   # opaque; () in core, TV2 owns meaning
    split_mode: bool = False
    cube1_position: Cell | None = None
    cube2_position: Cell | None = None
    active_cube: int | None = None
    # methods: occupied_cells() -> tuple[Cell,...]; to_dict()/from_dict() for Three.js JSON
# module helper: occupied_cells(state) -> tuple[Cell,...]

class Engine:
    def __init__(self, board: Board) -> None: ...
    def get_initial_state(self) -> State: ...               # STANDING at board.start
    def legal_actions(self, state) -> list[Action]: ...     # derived from transition; goal NOT terminal
    def transition(self, state, action) -> State | None: ...  # pure; None if off-board or hits VOID
    def is_goal(self, state) -> bool: ...                   # STANDING on board.goal and not split_mode
    def step_cost(self, state, action, next_state) -> float: ...  # always 1.0 (placeholder)
    # TV2 hooks (core returns trivial result): _roll, _cells_supported, _apply_tile_effects
```

`Board` (frozen): `rows, cols, start, goal, grid, bridges, switches, name`;
methods `in_bounds(cell) -> bool`, `tile_at(cell) -> TileType` (raises `IndexError` OOB).
Loaders: `load_board(path) -> Board` (JSON file), `parse_board(dict) -> Board`.

Core rule notes:
- Only off-board cells and `VOID` block a move; `FRAGILE`/`BRIDGE`/switch tiles are
  parsed but treated as plain floor (`# TODO(TV2)` hooks exist in `engine.py`).
- A lying block is supported on the goal but does **not** win.
- Illegal-move outcomes are `transition(...) is None`; "falling" is never a state.

## Level JSON schema (must stay reusable across all solvers)

```json
{"name": "level1", "grid": ["..###.....", "###S##...."], "bridges": [], "switches": []}
```

`grid` = array of equal-length strings. Chars: `#` FLOOR, `.` VOID, `S` start
(maps to FLOOR), `G` GOAL, `F` FRAGILE, `B` BRIDGE, `o` SOFT_SWITCH,
`x` HEAVY_SWITCH, `P` SPLIT_SWITCH. Exactly one `S` and one `G` required.
Loader raises `ValueError` (bad grid / not exactly one S or G), `TypeError`
(`bridges`/`switches` not a list, or JSON root not an object), `FileNotFoundError`.

## Solver contract (owned by `solvers/`; import from top-level `solvers`)

```python
def solve(initial_state: State, engine: Engine) -> SearchResult: ...   # per bfs/dfs/ucs/astar.py
# unified dispatcher: from solvers import solve_bfs, solve_dfs, solve_ucs, solve_astar

@dataclass
class SearchResult:
    solved: bool
    path: list[Action]
    total_cost: float
    search_time: float      # seconds
    memory_usage: float     # MB
    expanded_nodes: int
    solution_length: int    # len(path)
```

Solvers must only use the Engine API (`legal_actions`, `transition`, `is_goal`,
`step_cost`) — never inspect tiles/board internals.

## GUI contract (owned by `gui/`; details in `docs/gui_api.md`)

`main.py` launches `gui.app`. GUI drives every step via `engine.transition()` /
`engine.is_goal()` and never computes rules itself. Replay = sequential
`transition()` calls over `SearchResult.path`, keeping a history stack for
undo. Solver runs must not block the UI thread. Keybindings: arrows/WASD, `R`
restart, `U`/Backspace undo, Space switch-cube / pause.
